# Keitaro-wrapper

Тестовое задание. Реализация обёртки над Keitaro на Python + JavaScript.

## Запуск

Для запуска потребуется Docker Compose. Сервис запускается командой:
```console
docker compose up --build
```
Все зависимости и прочие необходимые для сборки файлы уже прописаны.

Перед запуском необходимо прописать API-ключ и адрес трекера в `.env`
backend-части. Запущенный сервис доступен по адресу `localhost:3000` (frontend)
и `localhost:8000` (backend).

## Миграции

В настоящей реализации миграции не используются, так как вся необходимая для
работы информация получается из базы Keitaro. SQLite используется только как
кэш.
